# User Guide

## Installation

To install the project, clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd source-of-truth
```

Install the necessary dependencies:

```bash
npm install
```

## Starting the Application

To start using the project, run the following command:

```bash
npm start
```

This will start the application and you should see output indicating that the server is running.

## Running Tests

To run tests using Jest, execute the following command:

```bash
npm test
```

This will run all the tests and provide a summary of the test results.

For more detailed information on each test, you can use:

```bash
npm test -- --verbose
```

## Troubleshooting

If you encounter any issues, please check the logs for error messages and ensure all dependencies are correctly installed. For further assistance, refer to the [Contact Information](mailto:support@example.com) section in the README.
